# WePost 项目演进路线图 (ROADMAP.md)

本文档记录 **WePost** 项目的核心功能演进规划与关键里程碑。

> **产品定位**：WePost 是**社交媒体卡片生成器**。把任意文字内容（金句、早报、随笔、开发笔记、态度观点等）结构化为 `CardData`，自动匹配模板与画幅，渲染为精美卡片并可导出高清图片，用于小红书、朋友圈、公众号封面等场景。

---

## 阶段一：卡片生成核心 (Phase 1) — 已完成 ✅

- [x] 项目工程骨架、Git 仓库与 CI/CD 规范初始化
- [x] AI Agent 协作体系与硬性约束定义 (`AGENTS.md`)
- [x] 卡片渲染引擎：画板舞台 (`CardStage`)、渲染器 (`CardRenderer`)、布局 (`CardLayout`)
- [x] 统一尺寸数据源 `getCanvasDimensions`，5 种画幅比例（3:4 / 1:1 / 9:16 / 2.35:1 / 4:3）
- [x] 10 套卡片模板：极简杂志、暗黑毛玻璃、复古报刊、温暖便签、东方留白、酸性潮流、水墨留白、终端代码、先锋杂志、霓虹赛博
- [x] 卡片内 Markdown 渲染 (`MarkdownRenderer`)：标题、段落、引用、列表、代码块
- [x] 内容编辑器：内容表单、样式工具栏、导出面板、顶栏、底部操作栏
- [x] 9 套内容预设 (`presets`)，灵感速选一键套用
- [x] 图片导出（`html-to-image` + `exporter`），支持 2x / 3x 缩放、PNG / JPEG
- [x] 撤销 / 重做历史 (`useCardHistory`)，含 `localStorage` 持久化与快捷键
- [x] 正文溢出预警 (`useCardOverflow`)
- [x] URL hash 预填充注入协议（`#card=base64url-json`）+ `gen-card-url.mjs` 编码工具
- [x] Cloudflare Pages 静态部署 (`wrangler`)
- [x] `wepost-card-gen` Claude skill，外部一键注入内容
- [x] 自动化测试基线（`vitest`，6 文件 51 用例全绿）
