## 一、极速上手：三步制作第一张卡片

无论你是在本地启动（`http://localhost:3000`）还是直接访问线上站（[wepost.zaneven.com](https://wepost.zaneven.com)），工作台分为左右两大区域：**左侧为编辑与设置面板**，**右侧为画板实时渲染舞台**。

### 步骤 1：录入内容
在左侧面板「内容编辑」中填写基础信息：
- **文章标题**：卡片的核心吸睛主题（支持换行与重点强调）；
- **作者信息**：显示在卡片角落的署名或公众号/小红书名称；
- **金句/副标题**：核心观点提炼，部分模板会以大字或引用样式醒目突出；
- **正文内容**：支持标准 Markdown 语法（标题、引用、粗体、列表、代码块等），画板会自动进行精细排版。

### 步骤 2：挑选模板与画幅
- 在顶部的「画幅比例」切换适合的目标平台（如小红书选 `3:4`，朋友圈选 `1:1`）；
- 在模板选择区点击任意模板，右侧舞台**毫秒级响应实时预览**。

### 步骤 3：高清导出
- 点击右上方「导出图片」按钮；
- 支持导出为 **2x / 3x 超清无损 PNG**，文件将自动保存至浏览器下载目录，直接可发社交平台。

## 二、画幅比例与场景选择指南

不同社交平台的最佳视觉画幅各不相同，WePost 内置了经过像素级调校的 5 种统一画幅：

| 画幅比例 | 适用平台与场景 | 特点与建议 |
| :--- | :--- | :--- |
| **3:4 (小红书/图文瀑布流)** | 小红书笔记、知乎想法、即刻动态 | 垂直视野大，信息容纳度高，小红书平台的官方黄金点击比例 |
| **1:1 (正方形)** | 微信朋友圈、Instagram、即刻单图 | 视觉聚焦感强，适合短小精悍的单句格言、态度观点或随感 |
| **16:9 (横版宽屏)** | 微信公众号首图封面、B 站动态、PPT 插图 | 影视级宽幅，适合作为公众号文章大封面或横屏信息概览 |
| **9:16 (坚屏全屏)** | 抖音/快手图文、微信视频号、Stories | 手机全屏沉浸式体验，适合长列表、多步骤指引或日签海报 |
| **4:3 (经典横版)** | 网页配图、技术博客 Banner、社群分享 | 比例温和，图文平衡，适合较宽的正文段落排版 |

## 三、10 套精选模板风格解析

1. **Modern Clean (现代极简)**：黑白灰极简美学，注重字距留白，适合认知思考、读书笔记。
2. **Minimal Dark (深邃暗黑)**：纯黑背景与高对比度文字，科技感十足，适合技术札记、架构心得。
3. **Warm Newspaper (复古报刊)**：拟真报刊排版、衬线字体与分栏设计，适合书评、深度随笔与文艺金句。
4. **Gradient Glow (炫彩渐变)**：活力弥散色彩背景，现代吸睛，非常适合小红书首图与爆款抓眼球。
5. **Polaroid Snapshot (拍立得胶片)**：留白相纸边框风格，生活感浓郁，适合摄影记录与日常碎碎念。
6. **Code Terminal (技术终端)**：黑客终端提示符与等宽代码字体，程序员写技术贴、Bug 排查的专属利器。
7. **Sticky Note (便签即时贴)**：手账便签风格，亲和力强，适合待办清点、Tips 窍门分享。
8. **Artisan Craft (手作质感)**：温润纸质纹理与自然色系，适合生活美学、人文艺术与哲学摘录。
9. **Editorial Magazine (杂志风尚)**：大字号排版与强烈的视觉主次，适合时尚资讯与态度观点。
10. **Bold Statement (态度主张)**：粗犷醒目的块面对比，冲击力极强，适合犀利锐评与宣言宣言。

## 四、进阶功能：长文智能拆卡与多图轮播

当你的文字内容较长（如一篇 1000 字的随笔）时，单张卡片排不下，WePost 提供了智能拆卡与多图管理能力：

### 1. 正文溢出智能预警
当输入的字数超过当前画幅的最佳视读高度时，界面会自动出现黄色溢出提示，提醒你内容已超过单页舒适区。

### 2. 一键内容切片（智能分页）
- 点击左侧的「**智能拆卡**」或手动使用分页符（在 Markdown 中插入 `---`）；
- 系统会自动将长文切分成多张卡片，右侧画板切换为多卡排列或轮播展示；
- 导出时可选择「**导出全部卡片**」，系统会自动打包或批量下载完整的多图序列（如 `card-1.png`、`card-2.png` ...）。

## 五、直达分发：一键推送微信公众号草稿箱（贴图号模式）

WePost 拥有全网独创的纯前端安全推送机制：**微信 AppID 与 Secret 仅保存在你的本地浏览器 localStorage 中，不入数据库、不经第三方云端**。

### 1. 为什么推荐「贴图号（newspic）」？
微信公众号的“图片消息”（即贴图号）是小红书式的横滑大图模式：
- 手机端打开直接横滑看图，极其贴合移动端快节奏阅读；
- 底部上滑可展开阅读纯文本；
- 完播率与分享率显著高于传统长图文。

### 2. 一键发布操作流程
1. **添加公众号白名单（一次性）**：
   - 登录微信公众平台 →「开发与设置 → 基本配置 → IP 白名单」；
   - 加入 ARM 服务器固定出口 IP：`168.107.32.13`（若使用本地伴侣模式，则添加本机当前出口 IP）。
2. **打开微信发布弹窗**：
   - 点击 WePost 顶栏右上角「**微信发布**」按钮；
   - 填写公众号的 `AppID` 与 `AppSecret`，点击「保存配置」；
   - 代理设置留空（系统默认全自动走固定出站代理）；
3. **设置发布参数**：
   - **文章标题**：自动抓取卡片主题，可微调；
   - **草稿类型**：默认勾选「**贴图号（图片消息）**」；
   - **内容组织**：选择「仅贴图」或「贴图 + 纯文本」（系统会自动清洗 Markdown 杂音符号）；
4. **点击「发布为贴图号」**：
   - 画板自动将每张卡片渲染为高清素材并同步至微信后台；
   - 成功后点击「前往草稿箱」或扫描临时预览码，直接在手机微信上审核并群发！

## 六、效率秘籍：预设、快捷键与自动化

### 1. 快捷键支持
- `⌘ + Z` (Mac) / `Ctrl + Z` (Windows)：撤销上次样式或内容变动；
- `⇧ + ⌘ + Z` / `Ctrl + Y`：重做；
- `ESC`：关闭当前弹窗。

### 2. 内置灵感预设
在内容编辑区点击「载入预设」，内置了精选样例文案（包括科技思考、随笔金句、代码日记），一秒看懂排版效果。

### 3. URL Hash 预填充协议（支持任何自动化工具）
WePost 支持通过 URL Hash 外部注入卡片数据：
```text
https://wepost.zaneven.com/#card=<base64url-json>
```
如果你在配合 Claude Agent、脚本或自动化流水线，只需把生成的 JSON 编码拼入 URL，打开即直接呈现设计好的卡片。

## 七、经典场景实战模板（可直接复制使用）

你可以直接复制以下 3 套排版内容到 WePost 的内容框中，一键体验最佳效果：

### 模板 A：金句思考型（适合小红书 / 朋友圈）
- **画幅**：`3:4` 或 `1:1`
- **推荐模板**：`Modern Clean` 或 `Bold Statement`
- **标题**：在喧嚣的时代，重塑深度思考的秩序
- **作者**：野生宝藏箱
- **金句**：重要的不是你读了多少信息，而是多少信息转化为了你的心智模型。
- **正文**：
  ```markdown
  现代人的注意力正被碎片的通知无情切割。
  
  要想在这个时代保持清醒：
  • 远离短周期的多巴胺诱惑
  • 建立自己的知识沉淀工作流
  • 每天保持至少 30 分钟的无网沉思
  
  认知不是被动接收的，而是主动重构的结果。
  ```

---

### 模板 B：程序员开发日志（适合技术社区 / 公众号）
- **画幅**：`3:4` 或 `4:3`
- **推荐模板**：`Code Terminal` 或 `Minimal Dark`
- **标题**：为什么我们决定把出口代理直接下沉到边缘节点
- **作者**：架构笔记
- **金句**：架构设计的本质，是在物理约束与研发体验之间找到最优雅的平衡点。
- **正文**：
  ```markdown
  今天排查了微信接口 40164 白名单的经典死锁：
  
  Serverless 边缘节点出口 IP 频繁漂移，导致调用微信 AccessToken 失败。
  
  ### 核心解决策略：
  1. 在 ARM 独立节点上启动极简反向代理
  2. Worker 边缘路由识别并透明转发
  3. 纯静态前端做到零配置直接穿透
  
  稳定性的第一法则是：**不要让不确定的外部边界污染核心系统。**
  ```

---

### 模板 C：生活文艺与书摘随感（适合朋友圈 / 小红书图文）
- **画幅**：`3:4`
- **推荐模板**：`Warm Newspaper` 或 `Polaroid Snapshot`
- **标题**：风吹过夏天留下的痕迹
- **作者**：迟暮随笔
- **金句**：生活不在别处，就在你凝视当下的每一个瞬间。
- **正文**：
  ```markdown
  翻开一本旧书，掉落出一片去年秋天夹在页缝里的落叶。
  
  时间好像走得很快，城市里的红绿灯闪烁不停，人群匆匆赶往下一个路口。
  
  但只要你停下来喝一杯茶，看一片云慢慢漫过屋顶，生活就会重新慢下来。
  
  愿我们都能在忙碌里，为自己保留一个小小的岛屿。
  ```
