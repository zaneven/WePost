# WePost 项目演进路线图 (ROADMAP.md)

本文档记录 **WePost** 项目的核心功能演进规划与关键里程碑。

---

## 阶段一：基础架构与排版核心 (Phase 1) - 当前阶段

- [x] 项目工程骨架、Git 仓库与 CI/CD 规范初始化
- [x] AI Agent 协作体系与硬性约束定义 (`AGENTS.md`)
- [ ] 核心 Markdown 解析引擎与 AST 转换设计
- [ ] 微信排版兼容的 CSS 样式内联器 (Juice 集成)
- [ ] 预置 3 套标准排版主题（极简黑白、优雅深绿、科技幽蓝）
- [ ] 代码块语法高亮（Prism/Shiki）与行号支持
- [ ] 数学公式（KaTeX/MathJax）转图片/SVG 渲染支持

---

## 阶段二：微信公众平台集成与创作台 (Phase 2)

- [ ] 微信公众平台开发者 API 对接（AccessToken 自动刷新与缓存）
- [ ] 永久图文素材 / 草稿箱一键同步发布
- [ ] 外链图片防盗链自动转存至微信素材库
- [ ] 实时分栏预览工作台（左侧 Markdown 编辑，右侧移动端渲染）
- [ ] 一键复制富文本至剪贴板（兼容微信公众号后台直接粘贴）

---

## 阶段三：AI 智能赋能与媒体库 (Phase 3)

- [ ] AI 辅助大纲扩写与内容润色功能
- [ ] 自动提取摘要、金句与敏感词排查
- [ ] 智能配图与封面图生成（集成火山方舟等生图能力）
- [ ] 媒体资产管理器（支持本地、TOS、S3 对象存储与压缩裁剪）

---

## 阶段四：多平台分发矩阵与团队版 (Phase 4)

- [ ] 多平台适配器：知乎、今日头条、小红书发布支持
- [ ] 批量发布任务调度队列与失败重试
- [ ] 多账号多渠道统一权限与团队协同
- [ ] 发布数据分析与阅读量回流看板
